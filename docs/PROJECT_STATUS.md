# Project status

**This is the first research release. Version 2 and real-robot experiments are in progress.**

| Track | Status | What is available here |
| --- | --- | --- |
| Paper v1 | Released | [arXiv:2611.09376v1](https://arxiv.org/abs/2611.09376v1), [PDF and source](../paper) |
| First code and artifact release | Released as [v0.1.0](https://github.com/jushengzhang/robot-weight-debugging/releases/tag/v0.1.0) | Experiment code, 16 session transcripts, episode records, and the evaluated 65-row edit |
| Version 2 | In progress | Further research; no v2 result is claimed in this release |
| Real-robot experiments | In progress | Physical-robot validation; no real-robot result is claimed in this release |

The published results concern simulated robot manipulation. Paper version **v1**
and code tag **v0.1.0** refer to this first release; they are different versioning
schemes. The tag identifies the initial code snapshot. Documentation improvements
continue on `main` without changing that snapshot. The attached paper artifacts
are the published arXiv v1, as recorded in [their provenance](../paper/provenance.json).
